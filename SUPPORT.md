# Getting help

Iridium Group projects are maintained by volunteers. There is no paid support, and there is no Discord server or chat channel. All support happens on GitHub.

## Questions

Read the project's README first. For general questions and conversation, use GitHub Discussions, which will be enabled on the `.github` repository.

## Bugs

If something does not work as documented, open an issue in the affected repository using the bug report form. Include the version, your environment, and the exact steps to reproduce the problem.

## Feature requests

Open an issue in the relevant repository using the feature request form. Describe the problem you are trying to solve, not only the solution you have in mind.

## Security issues

Do not report vulnerabilities in public issues or discussions. Follow the [security policy](./SECURITY.md) to report them privately.

## Contributing

To fix something yourself, see the [contributing guide](./CONTRIBUTING.md).
